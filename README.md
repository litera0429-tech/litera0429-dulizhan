# 肘子鱼 · 摄影作品集网站

一个纯静态的摄影作品集网站，集成 Decap CMS 无代码后台。部署到 Netlify 后，你可以直接在浏览器里上传图片、修改标题和分类，完全不需要接触代码。

## 项目结构

```
my-portfolio/
├── index.html            首页（全屏大图 + 沉浸浏览区：左侧目录 + 右侧大幅作品）
├── portfolio.html        冒险作品网格版（辅助视图，未放入导航）
├── business.html         肘子鱼的商业行迹（photo / 视频mv 筛选）
├── about.html            关于页（理念、经历、联系方式）
├── css/
│   └── style.css         全部样式（黑白灰极简风格）
├── js/
│   └── main.js           全部交互脚本（导航 / 主题 / 图片保护 / 站点内容 / 网格画廊 / 沉浸浏览）
├── images/
│   ├── home/             首页大图
│   ├── adventure/        冒险作品（tokyo/ hokkaido/ thailand/）
│   ├── commercial/       商业作品（photo/ video/）
│   └── uploads/          后台上传的新图会自动放在这里
├── content/              站点内容数据（后台可改）
├── admin/                无代码后台（Decap CMS）
└── README.md
```

## 本地预览

**方式一（推荐）：双击项目文件夹里的「启动网站.command」**，脚本会自动在正确目录启动服务器并打开浏览器。

**方式二：在项目根目录手动运行：**

```bash
python3 -m http.server 8000
```

然后浏览器打开 http://localhost:8000

如果看到 "Error response / 404 / File not found" 错误页，说明服务器不是在项目根目录（`my-portfolio/`）启动的；请改用「启动网站.command」，或先在终端 `cd` 到 `my-portfolio` 目录，再运行 `python3 -m http.server 8000`。

## 日 / 夜主题

网站会根据访问者本地时间自动切换黑白主题：

- 早上 6:00 到下午 17:00 → 浅色主题（白/浅色背景 + 深色文字）
- 下午 17:00 到次日早上 6:00 → 深色主题（黑/深色背景 + 浅色文字）

实现方式：每个页面的 `<head>` 里有一段小脚本，在首屏渲染前就设置 `data-theme`，`js/main.js` 每分钟同步一次，跨过 6:00 / 17:00 边界时也会自动切换；颜色全部走 CSS 变量，切换有 0.5s 平滑过渡。

## 部署并启用后台（推荐 Netlify，免费）

1. 把整个项目文件夹上传到 [Netlify](https://app.netlify.com)（拖拽文件夹或关联 Git 仓库均可）。
2. 部署完成后，打开 **Site settings → Identity**，点击 **Enable Identity**。
3. 在 Identity 里点击 **Services → Enable Git Gateway**（Git 网关）。
4. 访问 `https://你的站点域名/admin/`，用邮箱注册或登录（会收到验证邮件，输入验证码即可）。
5. 登录后即可在后台添加、删除、修改作品。

## 后台使用说明

后台有两个栏目：

**摄影作品 → 作品列表**

- 添加作品：点「新建」，填写作品名称、所属栏目（冒险/商业）、作品分类（东京/北海道/泰国/photo/视频mv）、上传图片，可写一句描述。
- 修改：点开任意作品即可改名、改分类、换图。
- 删除：点开作品后点删除按钮。
- 排序：在列表中上下拖动条目即可调整顺序。
- 保存后点「发布」，网站即更新。

**站点设置 → 首页与关于页**

- 首页大图、首页标题/副标题、关于页文字、关于页照片、联系邮箱都可以在这里改。

> 后台上传的图片会自动存入 `images/uploads/` 并显示在作品里，不需要手动放文件。

## 以后想新增作品，怎么操作？

三种方式任选：

1. **后台（推荐）**：访问 `/admin/` 登录 → 摄影作品 → 新建 → 填名称、选栏目/分类、传图 → 发布。
2. **手动改文件**：往 `content/works.json` 加一条记录（标题、栏目、分类、图片路径），并把图片放进 `images/` 对应目录。
3. **直接告诉我**：在 Codex 里说“在东京分类下加一张作品《新宿夜色》，图片放 work/ 里”，我会帮你完成一切。

想改文字、邮箱、首页大图、网站样式，同样可以直接在对话里告诉我。

## 图片规格建议

- 宽度控制在 2000px 以内（清晰度和加载速度的平衡点，也符合防盗图诉求）。
- 格式用 JPEG（照片）或 WebP，单张建议 500KB 以内。
- 文件名建议：`分类-名称-序号.jpg`，例如 `tokyo-shibuya-01.jpg`。

## 分类说明

当前可选分类：`东京`、`北海道`、`泰国`（冒险栏目）；`photo`、`视频mv`（商业栏目）。

想新增分类（比如“京都”或“广告片”）有两种方式：

- 让我在对话里帮你加（推荐，同时我会更新筛选菜单）；
- 自己改 `admin/config.yml` 里对应栏目的 `options`，保存后刷新后台即可出现新选项。

## 安全说明

网站已启用：

- 全局禁用鼠标右键菜单；
- 禁止拖拽图片到新窗口/本地；
- 移动端禁止长按保存（iOS `-webkit-touch-callout`）；
- 图片统一 2000px 以内。

> 注意：这些都是前端防护，只能提高盗用成本，无法 100% 阻止。如果作品很重要，建议加文字/半透明水印，或用图床防盗链。

## 常见问题

**打开 /admin/ 是空白或报错？**
确认站点已部署到 Netlify，并且已开启 Identity + Git Gateway。本地预览时后台默认不可用（见下一条）。

**想完全在本地用后台？**
安装 Node.js 后，在项目目录运行 `npx decap-server`，并把 `admin/config.yml` 里的 `local_backend` 改为 `true`，即可在本地体验后台；改回 `false` 则使用线上 Git 网关。

**后台发布后网站没变化？**
等 1–2 分钟让 Netlify 重新构建即可；也可以在 Netlify 的 Deploys 页面查看构建状态。

**想换一种部署方式（如 Vercel、Cloudflare Pages）？**
可以，但需要把后台的认证方式从 git-gateway 换成 GitHub OAuth（联系我或按 Decap CMS 文档配置）。
